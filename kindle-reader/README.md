# Kindle Reader

Веб-читалка для Kindle Paperwhite и обычного браузера. Она показывает книги из
Яндекс Диска и локальной библиотеки VPS, открывает FB2/TXT/EPUB/MOBI постранично, запоминает
место чтения и позволяет искать книги через Telegram-каталог прямо на сайте.

Рабочий адрес: [kindlereader.duckdns.org](https://kindlereader.duckdns.org/)
(требуется пароль владельца).

## Возможности

- интерфейс без тяжёлого JavaScript, рассчитанный на браузер Kindle;
- компактный экран чтения с одной панелью действий и без лишней вертикальной прокрутки;
- единый список книг из Яндекс Диска и локальной библиотеки;
- постраничный список по 10 книг с компактной навигацией;
- дата и время добавления каждой книги в часовом поясе UTC+5;
- чтение `.fb2`, `.fb2.zip`, `.txt`, `.epub` и `.mobi` постранично;
- локальный поиск и фильтр по автору;
- названия, авторы и компактные чёрно-белые обложки из метаданных книг;
- продолжение работы с локальными книгами при временной ошибке Яндекс Диска;
- сохранение последней страницы в SQLite;
- изменение размера шрифта;
- скачивание исходного файла;
- преобразование книги в MOBI или AZW3 через Calibre;
- поиск по названию или автору через Telegram прямо из браузера;
- отдельная кнопка выбора сразу под описанием каждой найденной книги;
- сохранение состояния поиска при обновлении страницы;
- удаление книги с отдельным экраном подтверждения;
- защищённый вход по паролю и подписанной cookie;
- дополнительный Telegram-бот для ручной отправки книг на Яндекс Диск.

## Как устроен проект

```text
Kindle / браузер
        |
        v
FastAPI + Jinja2
   |          |----------------------|
   v                                 v
Яндекс Диск                    Локальная библиотека VPS
(основные книги)               (импорт из веб-каталога)
                                      ^
                                      |
                         Telegram user session (Telethon)
                                      |
                                      v
                          @flibustafreebookbot
```

Есть два независимых способа добавления книг:

1. **Поиск на сайте.** Читалка обращается к книжному боту от имени отдельного
   Telegram-аккаунта. Выбранный файл сохраняется в `data/imported_books` на VPS.
2. **Ручная пересылка.** Собственный Telegram-бот принимает документ от
   разрешённого пользователя и загружает его в папку `YANDEX_BOOKS_PATH` на
   Яндекс Диске.

## Структура

| Путь | Назначение |
| --- | --- |
| `app/main.py` | веб-маршруты FastAPI |
| `app/catalog.py` | работа с Telegram-каталогом через Telethon |
| `app/catalog_jobs.py` | сохранение состояния фонового поиска |
| `app/books.py` | объединение удалённой и локальной библиотек |
| `app/formats.py` | единый список поддерживаемых форматов |
| `app/metadata.py` | кэш названий, авторов и уменьшенных обложек |
| `app/yandex_disk.py` | чтение и загрузка через REST API Яндекс Диска |
| `app/local_library.py` | защищённое локальное хранение импортированных книг |
| `app/parsers/` | разбор FB2/TXT и извлечение метаданных |
| `app/convert.py` | преобразование EPUB/MOBI в FB2 и скачивание MOBI/AZW3 |
| `app/progress.py` | сохранение позиции чтения в SQLite |
| `app/templates/` | HTML-шаблоны интерфейса |
| `app/static/style.css` | стили, совместимые со слабым браузером Kindle |
| `scripts/` | создание пароля и авторизация Telegram-аккаунта |
| `tests/` | автоматические тесты |
| `deploy/` | unit-файл дополнительного Telegram-импортера |

## Требования

- Python 3.11 или новее (на проде используется Python 3.12);
- доступ к Яндекс Диску по OAuth-токену;
- Calibre с командой `ebook-convert` для EPUB/MOBI и скачивания в формате Kindle;
- Pillow (устанавливается через `requirements.txt`) для безопасного уменьшения обложек;
- отдельный Telegram-аккаунт, `api_id` и `api_hash` — только для поиска на сайте;
- HTTPS и обратный прокси для публичного запуска.

## Быстрый локальный запуск

```bash
cd kindle-reader
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Создайте ключ для подписания сессии:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Создайте хэш пароля:

```bash
python scripts/hash_password.py "надежный-пароль"
```

Запишите полученные значения и настройки Яндекс Диска в `.env`, затем запустите:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Локальный адрес: `http://127.0.0.1:8000`.

## Настройки `.env`

Скопируйте `.env.example` в `.env`. Сам файл `.env` не должен попадать в Git.

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `YANDEX_TOKEN` | да | OAuth-токен Яндекс Диска |
| `YANDEX_BOOKS_PATH` | да | папка с книгами, например `/Книги` |
| `SECRET_KEY` | да | ключ подписи cookie и кнопок каталога |
| `PASSWORD_HASH` | да | хэш пароля входа |
| `PASSWORD_SALT` | да | соль пароля в hex-формате |
| `CHARS_PER_PAGE` | нет | примерный объём одной страницы, по умолчанию `1600` |
| `COOKIE_SECURE` | да на проде | `true` для HTTPS, `false` для локального HTTP |
| `TELEGRAM_API_ID` | для каталога | ID приложения с `my.telegram.org` |
| `TELEGRAM_API_HASH` | для каталога | секрет приложения Telegram |
| `TELEGRAM_SESSION_PATH` | нет | путь к пользовательской Telegram-сессии |
| `TELEGRAM_SOURCE_BOT` | нет | бот-источник, по умолчанию `flibustafreebookbot` |
| `TELEGRAM_CATALOG_TIMEOUT_SECONDS` | нет | ожидание ответа каталога, по умолчанию 25 секунд |
| `TELEGRAM_ACTION_MAX_AGE_SECONDS` | нет | срок действия кнопки результата |
| `LOCAL_BOOKS_PATH` | нет | локальная папка импорта из веб-каталога |
| `CATALOG_JOBS_PATH` | нет | папка сохранённых поисковых операций |
| `CATALOG_JOB_TTL_SECONDS` | нет | срок хранения операции, по умолчанию 24 часа |
| `TELEGRAM_BOT_TOKEN` | для моста | токен собственного бота от BotFather |
| `TELEGRAM_ALLOWED_USER_IDS` | для моста | разрешённые Telegram user ID через запятую |
| `TELEGRAM_MAX_FILE_SIZE_MB` | нет | максимальный размер принимаемой книги |
| `KINDLE_READER_PUBLIC_URL` | для моста | публичная ссылка на библиотеку |

Никогда не публикуйте `.env`, Telegram session-файл, токены, пароли и резервные
копии каталога. Они исключены из Git через `.gitignore`.

## Подключение поиска через Telegram

1. Создайте отдельный Telegram-аккаунт.
2. Откройте `@flibustafreebookbot` и нажмите **Start**.
3. На [my.telegram.org](https://my.telegram.org/) откройте **API Development
   tools**, создайте приложение и получите `api_id` и `api_hash`.
4. Выполните из папки `kindle-reader`:

   ```bash
   python scripts/telegram_login.py
   ```

5. Введите номер телефона, код Telegram и облачный пароль, если он включён.
6. Запустите приложение и откройте `/catalog`.

Файл `data/telegram_catalog.session` фактически даёт доступ к отдельному
Telegram-аккаунту. Его нельзя отправлять другим людям или добавлять в Git.

Поиск выполняется в фоне. Идентификатор операции остаётся в адресе страницы,
поэтому обычное обновление не сбрасывает прогресс. Результат хранится до времени,
указанного в `CATALOG_JOB_TTL_SECONDS`.

## Дополнительный Telegram-мост на Яндекс Диск

Этот режим нужен, если книгу пересылают вручную собственному боту.

1. Создайте бота через `@BotFather`.
2. Укажите `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USER_IDS` и
   `KINDLE_READER_PUBLIC_URL` в `.env`.
3. Запустите:

   ```bash
   python -m app.telegram_bot
   ```

4. На Linux можно установить `deploy/kindle-telegram-bot.service` в systemd.

Мост принимает только личные сообщения от разрешённых ID, проверяет формат и
размер, не перезаписывает существующие книги и сохраняет их на Яндекс Диск.

## Поддерживаемые форматы

| Действие | Форматы |
| --- | --- |
| Чтение в браузере | FB2, FB2.ZIP, TXT, EPUB, MOBI |
| Импорт через каталог | FB2, FB2.ZIP, TXT, EPUB, MOBI |
| Ручная пересылка боту | FB2, FB2.ZIP, TXT, EPUB, MOBI |
| Скачивание для Kindle | MOBI, AZW3 при установленном Calibre |

EPUB и MOBI перед чтением автоматически преобразуются во временный FB2 и
кэшируются в памяти процесса. PDF не поддерживается.

Метаданные обрабатываются небольшими порциями только для видимой страницы, чтобы
не перегружать VPS и Яндекс Диск. После первого открытия страницы нажмите
**Проверить готовность**, чтобы увидеть найденные названия, авторов и обложки.
Поиск по имени файла работает сразу; поиск по автору и названию становится полнее
по мере заполнения кэша метаданных.

## Данные и резервные копии

Каталог `data/` создаётся автоматически и не хранится в Git:

- `data/progress.db` — последняя страница каждой книги;
- `data/book_meta.db` — кэш названий, авторов и наличия обложек;
- `data/covers/` — уменьшенные чёрно-белые JPEG-обложки;
- `data/imported_books/` — книги, добавленные через поиск на сайте;
- `data/catalog_jobs/` — незавершённые и завершённые поисковые операции;
- `data/telegram_catalog.session` — авторизованная Telegram-сессия;
- `data/telegram_offset.txt` — позиция опроса дополнительного бота.

Для полного восстановления нужны резервные копии `.env` и `data/`. Храните их
отдельно от репозитория и ограничьте доступ к ним.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты не используют реальные токены и не должны обращаться к рабочему аккаунту

## Развёртывание

Рекомендуемая схема для VPS:

1. код находится в отдельной директории исходников;
2. приложение копируется в `/opt/kindle-reader` без `.env`, `.venv` и `data`;
3. зависимости устанавливаются в виртуальное окружение;
4. FastAPI запускается отдельной службой systemd от непривилегированного
   пользователя;
5. наружу приложение публикуется через Nginx/Caddy по HTTPS;
6. после обновления проверяется `http://127.0.0.1:8000/login`;
7. перед заменой файлов создаётся резервная копия с возможностью отката.

На текущем сервере обновление выполняет административный сценарий
`/usr/local/sbin/deploy-kindle-reader`, который забирает ветку `main`, создаёт
резервную копию, перезапускает службу и проверяет доступность приложения.

Стабильная версия перед добавлением EPUB/MOBI и метаданных отмечена Git-тегом
`kindle-reader-stable-2026-08-26`. Перед развёртыванием также создаётся закрытая
резервная копия `.env` и всего каталога `data/` на VPS. Это позволяет вернуть не
только код, но и прежнее состояние библиотеки, прогресса и Telegram-сессии.

## Основные страницы

| Адрес | Назначение |
| --- | --- |
| `/login` | вход |
| `/` | общая библиотека |
| `/?q=...&author=...` | поиск и фильтрация библиотеки |
| `/catalog` | поиск через Telegram |
| `/read?path=...` | чтение книги |
| `/download?path=...` | скачивание исходника |
| `/download?path=...&fmt=mobi` | конвертация и скачивание для Kindle |
| `/refresh` | обновление списка книг |
| `/delete?path=...` | подтверждение удаления книги |
| `/cover?path=...` | защищённая выдача уменьшенной обложки |

Книги Яндекс Диска при удалении перемещаются в корзину. Локальные книги из
`data/imported_books` удаляются безвозвратно, поэтому для них всегда показывается
явное предупреждение перед подтверждением.

## Частые проблемы

- **Яндекс Диск отвечает 401.** Токен отсутствует, неверен или отозван.
- **Яндекс Диск отвечает 403.** У токена обычно недостаточно прав на нужную
  папку или операцию. Выпустите токен с чтением и записью и проверьте, что
  `YANDEX_BOOKS_PATH` доступен этому приложению.
- **Каталог не настроен.** Проверьте `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и
  наличие session-файла, затем повторите `telegram_login.py`.
- **Каталог долго отвечает.** Повторите запрос позже; Telegram-бот может временно
  задерживать ответ.
- **После обновления остался старый вид результатов.** Запустите новый поиск:
  ранее завершённая операция хранит снимок старой выдачи до истечения TTL.
- **Не работает кнопка Kindle.** Установите Calibre и убедитесь, что команда
  `ebook-convert` доступна службе приложения.
- **Книга не появилась.** Нажмите «Обновить список»; список кэшируется примерно
  на пять минут.

Используйте интеграцию с внешними каталогами только для материалов, которые вы
имеете право получать и читать.
