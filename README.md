# gap-kasha

Монорепозиторий содержит несколько частей проекта:

| Каталог | Назначение |
| --- | --- |
| [`kindle-reader/`](kindle-reader/) | веб-читалка для Kindle, Яндекс Диска и Telegram-каталога |
| [`app/`](app/) | Android-приложение GapKassa |
| [`local-backend/`](local-backend/) | серверная часть GapKassa |
| [`docs/`](docs/) | технические заметки и инструкции по развёртыванию |

Полная инструкция по установке, настройке и эксплуатации читалки находится в
[`kindle-reader/README.md`](kindle-reader/README.md).

Секреты и пользовательские данные (`.env`, токены, Telegram-сессии, книги,
SQLite-базы и резервные копии) не должны добавляться в Git.
